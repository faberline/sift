# ADR 0002: DDD phase P2, first batch

- **Status:** Accepted. The four rounds below were approved together on
  2026-09-30 and are applied on `refactor/ddd-p2`.
- **Date:** 2026-09-30
- **Applies to:** everything under `src/` and `tests/`, and the `docs/` pages
  that describe them. Behaviour, the CLI and persisted bytes do not change.

## Context

P1 ([ADR 0001](0001-ddd-layout.md)) moved Sift into the DDD layout without
changing behaviour. It recorded every rule break it did not fix as a
`ddd.toml` exception, 78 in all. Two files stayed C1 warnings because each
holds one function above 400 lines (E9). P2 removes those exceptions and
warnings, each change approved on its own. This ADR records the first batch
and the decisions made for it.

ADR 0001 said other repos import Sift by its module paths. None does. Only
Sift's own binary and integration tests use them, so the compatibility
facades could go once those callers moved.

## Decision

### Scope

Four rounds, in this order:

1. **Structure.** Delete the dead batch ingest code (X1, X2). Remove the
   compatibility facades. Move cold-query replay from the archive to the
   query context. Rename `JournalState` to `ResidentWindow`. Split the two
   E9 functions.
2. **Domain errors (E6).** The domain layers and the shared kernel use
   thiserror instead of `anyhow`.
3. **Domain clock reads (E7).** Domain code takes `now` as an argument.
4. **Small cleanups.** X3–X6 and X10: one single-signal check, one default
   query limit, one UTF-8 truncation, one SHA-256 hex helper and one
   manifest-hash check.

Each of these is left for a later batch, planned and approved on its own:

- the journal–archive and other ports
- `ServiceState` accessors
- a `Clock` port
- X7–X9
- approving or removing each remaining B2 crate
- the other B3 layer fixes

### Rules every commit follows

- **Behaviour is unchanged.**
  - Error Display text stays the same.
  - `sift spec` with the OpenAPI document, `sift --help` and every
    subcommand's `--help` stay byte-identical to `main`.
  - Deleting the dead batch code also deleted that code's unit tests.
- **`ddd.toml` only shrinks.**
  - No commit adds an exception.
  - A new file inherits an exception only through `[[renames]]`, from the
    file it replaces within the same exception.
  - A commit that fixes a break deletes the break's entry.
- **Each commit passes every check.** It builds with no warnings, adds no
  clippy findings, passes the full test suite and passes
  `rust_arch_contract.py check --strict`.

### Public paths

- **Where public items live.**
  - Every context is a `pub mod`, and its module file re-exports the
    context's public items, so a caller writes `sift::<context>::Item`.
  - The layers stay `pub(crate)`.
  - The crate root keeps its re-exports, including the whole event model.
    The model is defined in the private shared kernel.
- **Nothing is dropped.** When a facade goes, every item it exported stays
  public. Dropping an item nothing uses would be deleting code, which is an
  X item.
- **Renamed re-exports.** A name that would not say what it is at the
  context root gets a prefix, with `as`, when it is re-exported:
  - `mcp_http_router`, `serve_mcp_stdio` and `mcp_tool_names`
  - `run_operator`
  - `serve_otlp_grpc` and `serve_otlp_grpc_proxy`
  - `decode_otlp`, `encode_otlp_response` and `normalize_otlp_payload`
- **No protobuf re-exports.** Third-party protobuf types are not
  re-exported. Callers use `transport_otlp::proto` and
  `metrics_remote_write::proto`, which are already normal dependencies.
- **Imports inside the crate.** Code inside the crate imports each item from
  the module that defines it, not from a context root.

[architecture.md](../architecture.md#public-api) lists every old path and
what replaced it.

### Splitting the two long functions (E9)

- **Mechanical extraction.**
  - Each block moves into a function unchanged.
  - State that a block changes is passed by `&mut`.
  - Nothing is merged or de-duplicated in the same commit.
  - No test is added first.
- **Checking the lifecycle worker.** Its replicated branch has no test.
  Instead, a script finds every moved line in the original function, in the
  same order.

### Domain errors (E6)

- **One enum per module.** Each domain module gets one error enum. It goes in
  the same file or in a sibling `*_error.rs`.
- **Display text stays the same.**
  - `.context("X")` around another error becomes `#[error("X")]` with a
    `#[source]` field, not `"X: {0}"`. Otherwise `{:#}` would print the cause
    twice.
  - `.context` on an `Option` becomes a plain variant.
  - A bare `?` becomes `#[error(transparent)]`.
- **Other layers keep `anyhow`.** The application and infrastructure layers
  keep it, and `?` converts.

### Domain clock reads (E7)

- **The rule.** A domain function takes `now` as an argument, and a caller
  outside the domain reads the clock. This is the shape
  `retention_rejection_at` already has.
- **No `Clock` port.** There is none in this batch.
- **Other layers.** Application and infrastructure code keeps its own
  `Utc::now` calls.

## Consequences

- There are no compatibility facades. Every public path is a crate-root
  re-export or `sift::<context>::Item`.
- The planned count is 46 exceptions after the fourth round, and no C1
  warnings.
- The remaining exceptions are the next batches' backlog. Each exception's
  reason still says what removes it.
